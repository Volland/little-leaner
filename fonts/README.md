# Fonts

WOFF2 subsets (Latin, Greek, arrows, mathematical operators; JuliaMono also brackets, dingbats and sub- and superscripts, for Lean) of the book's fonts in
`typst/fonts/`, made with fontTools `pyftsubset --flavor=woff2`.
